  1. 001

    The model is read once

    Every element's properties are cleaned into one table: units converted, Revit's naming untangled, empty values marked as not set.

  2. 002

    Your question becomes a query

    Plain questions are matched in code. Anything subtler is written as a query by AI, using only names that exist in your model.

  3. 003

    The query is checked

    It may only read the model table, one query at a time. Anything that would change data is refused before it runs.

  4. 004

    You see the evidence

    The answer, the elements highlighted in 3D, and where each value came from in Revit. Rate it, and wrong answers are learned from.

What it can't answer, and says so

Augmented answers from the properties Revit exports and the element positions in the 3D view. When a question needs data that isn't there, you get a straight answer instead of a guess.

  • Not in the data

    Which elements are connected or support each other

  • Not in the data

    Clashes and overlaps

  • Not in the data

    Grid lines and building orientation

  • Often missing

    Level elevations, when the model doesn't export them

  • Read-only

    Changing the model: it only reads
